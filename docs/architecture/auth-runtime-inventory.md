## Explicit answers

| Question                       | Answer                                                                                                                                   |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Access token TTL               | Env `JWT_EXPIRES_IN`, default `"7d"` (`auth.service.ts`, `.env.example`)                                                                 |
| Maximum legacy token TTL       | No dedicated symbol. Practical max = `JWT_EXPIRES_IN` at issuance (default 7d). Denylist fallback `FALLBACK_TTL_MS` = 7d                 |
| Redis on authenticated request | `AuthGuard` → `TokenDenylistService.isRevoked(jti)` → L1 Map miss → `GET nbos:jwt-denylist:{jti}` when `REDIS_STATE_URL`/`REDIS_URL` set |
| Logout semantics               | Clear Auth.js cookie; best-effort Nest logout denylists current `jti`; vault unlock cleared; **not** all-user revoke                     |
| Password reset                 | Not implemented                                                                                                                          |
| User disable/terminate         | Blocks login + EmployeeGuard; **does not** denylist outstanding JWTs                                                                     |
| Socket.IO token                | Realtime-token BFF route → full access JWT in handshake                                                                                  |
| SSE/BFF auth                   | `getToken` / `getBackendAccessToken` → Bearer to Nest                                                                                    |
| Permissions                    | **Not in JWT**; loaded from DB each request (60s memory cache)                                                                           |
| CSRF                           | Nest `OriginGuard` (allow missing Origin); Auth.js CSRF cookies on `/api/auth/*`                                                         |
| localStorage tokens            | None for auth                                                                                                                            |
